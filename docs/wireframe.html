Product plan · working name “Cadence”

An AI scheduler that decides when the work actually happens

Import your syllabi, shifts, and deadlines. Answer a short questionnaire. The AI lays homework and prep onto a Google-Calendar-style grid you can see, toggle by calendar, and drag around — and it re-plans around every edit you make.

Features by release

v1 · MVP

The core loop

  • Multiple calendars — create, color, toggle visibility (like Google Calendar)
  • Tasks with due date, effort estimate, and priority
  • Syllabus import → AI extracts dates → you confirm before anything lands
  • Onboarding questionnaire → your work hours & focus habits
  • Auto-schedule tasks into free time as a preview you accept
  • Drag to tweak; the rest re-flows around your edit
  • Week / Day / Month views
v2 · smarter

When it earns trust

  • Fell-behind rebalancing — “missed 2 blocks, reschedule?”
  • Time-of-day energy — deep work AM, admin PM
  • Recurring tasks & templates (weekly reading, gym 3×)
  • Reminders before blocks and deadlines
  • Task dependencies (B waits on A)
  • Two-way iCal / Google sync
v3 · the website

Opening it to users

  • Accounts & auth, isolated per-user data
  • Shared calendars for a club or lab team
  • Mobile-friendly, installable PWA
  • Analytics — estimated vs. actual, where the week went

How it stays maintainable

Clean seams

  • Frontend (React + TS + Vite) only renders & edits
  • Backend (FastAPI or Node) owns parsing & scheduling
  • Either side can change without breaking the other

Scheduler is a pure function

  • (tasks, events, constraints) → plan
  • Deterministic, unit-testable, swappable
  • Start simple & greedy; refine later

AI stays contained

  • LLM does two jobs: read syllabi, suggest a plan
  • Always behind a human-review step
  • A bad AI output never silently corrupts your calendar

Suggested build order

01

Calendar shell

Sidebar + week grid, hardcoded events. Learn the UI.

02

Calendars + tasks

CRUD, colors, visibility toggles. No AI yet.

03

Deterministic scheduler

Turn tasks into work blocks. Drag + re-flow.

04

Add the AI

Questionnaire → syllabus import → suggestions.

05

Go multi-user

Auth + Postgres → the public website.
